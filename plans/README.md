# Historical reviews and implementation records

Files in this directory are dated review evidence and implementation
snapshots. They describe repository states that existed when each document was
written and may mention retired playbooks, versions, findings, or rollout
steps.

They are retained locally for audit history and excluded from the public Git
tree, except for this explanation. They are not operator instructions. Use
the repository root `README.md`, current playbooks, and `make validate` as the
authoritative interfaces.
