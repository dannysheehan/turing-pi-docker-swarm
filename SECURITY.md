# Security policy

## Reporting a vulnerability

Do not disclose credentials, tokens, private infrastructure details, or a
suspected vulnerability in a public issue.

Use GitHub's **Report a vulnerability** private-reporting interface for this
repository. Include the affected file or workflow, impact, reproduction steps,
and any suggested mitigation. Remove real secrets and personal data from all
examples.

Security reports will be acknowledged and assessed before public disclosure.
There is currently no guaranteed response-time or supported-release window.
